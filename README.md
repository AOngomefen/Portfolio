# AndreaOS v1.0 — Portfolio

> *A personal portfolio website styled as an interactive desktop OS experience — currently in active development.*

**Live Site:** [ongomefen.com](https://ongomefen.com) &nbsp;|&nbsp; **Author:** [Andrea Ongomefen](https://linkedin.com/in/andreaongomefen)

## Overview

This is my personal portfolio, built from scratch with vanilla HTML, CSS, and JavaScript. The design concept is an **OS-inspired interface** — windows, icons, glassmorphism panels, and animated backgrounds — that doubles as a creative showcase of my technical and design capabilities.

The site is actively being developed. New pages, features, and integrations are added regularly.

## Features

### Spotlight Carousel
An interactive slideshow on the Projects page that highlights featured work including:
- **Global CO₂ Emissions EDA** — trend analysis across 2000–2014 with embedded Slides.com presentation
- **HIV/AIDS Diagnosis by NYC Borough** — demographic breakdown across a decade of public health data
- **Spline 3D Rendering** — interactive 3D background built in Spline
- Keyboard navigation supported (`← →` arrow keys)

### Project Preview Grid
A dynamically generated card grid linking out to individual GitHub repositories and notebooks including:
- CO₂ Global Emissions EDA
- Employee Absence Tracker (C++)
- Unit Converter (C++)
- Hotel Occupancy Calculator (C++)
- Movie Ticket Booth / Input Validation (C++)
- Women's Happiness Global Index

### About / CV Page
Functions as an interactive resume featuring:
- Personal bio and professional background
- Tech stack icon display (C++, Python, Java, SQL, Pandas, HTML5, CSS3, GitHub, Figma)
- LinkedIn profile badge
- Certifications and academic honors

### Design System
- **Glassmorphism** UI throughout (`glass-box` component)
- **Spline** 3D animated backgrounds
- **Animated GIF** assets for personality and visual identity
- Bootstrap 5 integrated for layout support
- Fully custom `styles.css`
